# Lucky 38 — Колесо Фортуны

Мини-игра в стиле Fallout: New Vegas: колесо фортуны, доска контрактов, еженедельные карточки, монеты.

- `index.html` — сайт для игрока
- `admin.html` — панель управления (также доступна через ⚙ в правом нижнем углу сайта)

Данные хранятся в Supabase (таблица `game_state`, ключи `fnv_*`).
Хостинг — Netlify, деплой автоматически при каждом push в `main`.
